# Free Tools Status

## Current Status

The `free-tools.html` page is currently hidden from the public site navigation and main user journeys.

## Why It Is Hidden

The free tools section needs more thought before it is promoted. The current page includes useful ideas such as:

- CV Score Checker
- Scholarship Match Quiz
- Japa Readiness Score
- SOP Mistake Checklist
- Visa Document Checklist

However, the final strategy for these tools is not yet decided. They may later become lead magnets, email capture tools, assessment forms, or a more polished free resource section.

## What Was Hidden

The following visible entry points were removed or redirected:

- `Free tools` link in the shared header
- Free tools section on the homepage
- Free readiness tool card on the contact page
- Free-tools CTAs on CV and scholarship pages

The actual `free-tools.html` file was not deleted.

## How To Bring It Back Later

When ready, restore links to `free-tools.html` from:

- `header.html`
- `index.html`
- `contact.html`
- Relevant service pages such as `cv-writing.html` and `scholarship.html`

Also remove the temporary `noindex, nofollow` meta tag from `free-tools.html` if the page should be discoverable by search engines.
